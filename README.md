# Calendar Activity

Интерактивный календарь активностей Level Group / Media Instinct Group.

## Возможности MVP

- переключение месяцев и лет;
- редактирование команды, направления и названия задачи прямо в таблице;
- заливка календарных ячеек цветом, протягивание мышью и очистка;
- отметка дедлайнов `ДЛ`;
- список пяти ближайших дедлайнов относительно текущей даты;
- явное сохранение данных в браузере;
- экспорт и импорт резервной копии в JSON.

## Хранение данных

MVP использует `localStorage`: данные доступны только в том браузере, где были сохранены. Для общего многопользовательского календаря потребуется подключить серверное хранилище и авторизацию.

Сайт не требует сборки и публикуется напрямую через GitHub Pages.
