# Calendar Activity

Интерактивный календарь активностей Level Group / Media Instinct Group.

## Возможности MVP

- переключение месяцев и лет;
- редактирование команды, направления и названия задачи прямо в таблице;
- заливка календарных ячеек цветом, протягивание мышью и очистка;
- отметка дедлайнов `ДЛ`;
- список пяти ближайших дедлайнов относительно текущей даты;
- сохранение данных в общей базе Supabase;
- автоматическое получение серверных изменений в открытом календаре;
- защита от случайной перезаписи более новой серверной версии;
- экспорт и импорт резервной копии в JSON.

## Хранение данных

Основное состояние хранится в одной записи таблицы Supabase `calendar_state`. Любой посетитель сайта может прочитать и изменить календарь. `localStorage` используется только как резервная копия на случай временной недоступности сервера.

### Настройка Supabase

1. Создать проект Supabase.
2. Выполнить [`supabase/schema.sql`](supabase/schema.sql) в SQL Editor.
3. Скопировать URL проекта и publishable key в `config.js`, используя `config.example.js` как образец. Publishable key разрешено размещать во фронтенде; `service_role` или secret key использовать нельзя.
4. Открыть календарь. Если строки `shared` ещё нет, первый запуск перенесёт текущую локальную копию в общую базу.

Политики RLS разрешают анонимным посетителям только чтение, создание и изменение единственной записи `shared`; удаление запрещено. Такая модель соответствует открытому режиму «любой пользователь со ссылкой» и не подходит для закрытых или чувствительных данных.

Сайт не требует сборки и публикуется напрямую через GitHub Pages.
