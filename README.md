# Calendar Activity

Интерактивный календарь активностей Level Group / Media Instinct Group.

## Возможности MVP

- переключение месяцев и лет;
- редактирование команды, направления и названия задачи прямо в таблице;
- заливка календарных ячеек цветом, протягивание мышью и очистка;
- отметка дедлайнов `ДЛ`;
- список пяти ближайших дедлайнов относительно текущей даты;
- сохранение данных через собственный API на сервере Selectel;
- автоматическое получение серверных изменений в открытом календаре;
- защита от случайной перезаписи более новой серверной версии;
- экспорт и импорт резервной копии в JSON.

## Хранение данных

Основное состояние хранится в JSON-файле на сервере Selectel и доступно через небольшой HTTP API. Любой посетитель сайта может прочитать и изменить календарь. `localStorage` используется только как резервная копия на случай временной недоступности сервера.

### Настройка API

1. Разместить [`server/calendar-api.mjs`](server/calendar-api.mjs) за HTTPS-прокси.
2. Создать начальный файл данных по образцу [`server/calendar-data.example.json`](server/calendar-data.example.json).
3. Указать публичный адрес API в `config.js`, используя `config.example.js` как образец.

API принимает запросы только от заданного origin, ограничивает размер тела и использует номер ревизии для защиты от случайной перезаписи более новой версии. Модель остаётся открытой для любого пользователя, имеющего ссылку на календарь, и не подходит для чувствительных данных.

Сайт не требует сборки и публикуется напрямую через GitHub Pages.
